# Tery's Stroy

책장을 넘기듯 미스터리를 탐색하는 디지털 스토리 아카이브입니다. 설명되지 않은 사건, 잊힌 장소, 미지의 신호를 기록물 형태로 수집하고 분류해 독자가 단서를 따라가며 자신만의 결론을 만들어 가도록 설계했습니다.

> 현재 화면에 표시되는 사건 기록은 인터페이스와 정보 구조를 보여주기 위한 픽션·샘플 콘텐츠입니다.

## 프로젝트 목표

- 흩어진 미스터리 이야기를 사건·장소·시대·유형별로 체계화합니다.
- 파일, 도장, 증거 보드 같은 기록물의 시각 언어로 몰입감을 만듭니다.
- 검색과 카테고리를 통해 원하는 이야기에 빠르게 접근할 수 있게 합니다.
- 새로운 기록과 기능을 계속 추가할 수 있는 확장 가능한 아카이브를 구축합니다.

## 브랜드

- **이름:** `Tery's Stroy`
- **로고:** 펼친 책 안에 물음표가 들어간 심볼
- **톤:** 오래된 사건 파일, 종이 기록, 붉은 기밀 도장을 연상시키는 편집 디자인
- **컬러:** 아이보리 페이퍼, 차콜 잉크, 아카이브 레드

로고는 이미지 파일 대신 CSS 도형과 텍스트로 구성해 화면 크기에 관계없이 선명하게 표시됩니다.

## 현재 구현

- 반응형 브랜드 헤더와 책·물음표 로고
- 대표 사건 파일 형식의 히어로 섹션
- 사건·장소·인물 검색 인터페이스
- 아카이브 현황 통계
- 샘플 사건 카드와 기록 열람 흐름
- 프로젝트 목적과 핵심 기능을 설명하는 소개 섹션
- 픽션·샘플 콘텐츠 고지
- 모바일·태블릿·데스크톱 반응형 레이아웃
- 키보드 탐색과 모션 감소 설정을 고려한 접근성 스타일

## 기술 구성

- Next.js 호환 Vinext 구조
- React 19
- TypeScript
- Tailwind CSS 4 및 커스텀 CSS
- Cloudflare Workers 호환 빌드 구성

## 실행 방법

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run dev
```

배포용 빌드는 다음과 같이 생성합니다.

```bash
npm run build
```

## 주요 파일

- `app/page.tsx` — 메인 콘텐츠와 아카이브 구조
- `app/globals.css` — 브랜드, 로고, 기록물 스타일과 반응형 규칙
- `app/layout.tsx` — 사이트 언어와 메타데이터
- `.openai/hosting.json` — ChatGPT Sites 배포 구성
